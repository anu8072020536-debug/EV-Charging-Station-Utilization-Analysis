 📊 Project Overview

This project analyzes Electric Vehicle (EV) charging station data using Microsoft Power BI.

The dashboard provides insights into charging sessions, energy consumption, charging duration, revenue, stations, users, facility types, weekdays, and platform usage.

🎯 Project Objectives

- Analyze EV charging station utilization
- Identify charging patterns by weekday and hour
- Understand energy consumption across facility types
- Analyze charging sessions by platform
- Compare charging activity across stations
- Track revenue generated from charging sessions
- Identify useful patterns for improving EV charging operations

 🔍 Key Insights

The dashboard helps identify peak charging periods, energy consumption patterns, frequently used charging stations, facility-level usage, and platform preferences.

These insights can help EV charging businesses improve station utilization, operational planning, and customer experience.
